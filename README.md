# Домашнє завдання №3 (Тема 6) — Пошук зображень (Pixabay API)

Проєкт являє собою застосунок для пошуку та перегляду зображень за ключовим
словом з використанням публічного Pixabay API.

## Використаний стек технологій

- **Збірка:** Vite
- **Мова:** JavaScript (ES6+ Модулі)
- **Стилізація:** CSS3 (Grid, Flexbox)
- **Бібліотеки:** \* [Axios](https://axios-http.com/) — для виконання
  HTTP-запитів
  - [iziToast](https://izitoast.marcelodolza.com/) — для відображення спливаючих
    сповіщень
  - [SimpleLightbox](https://simplelightbox.com/) — для створення адаптивної
    галереї з модальним вікном

## Функціонал

1. Пошук зображень за текстовим запитом користувача.
2. Валідація порожнього інпуту (попередження від `iziToast`).
3. Текстовий індикатор завантаження `Loading images, please wait...` під час
   очікування відповіді від сервера.
4. Відображення результатів у вигляді адаптивної сітки (Pixel Perfect за макетом
   Figma).
5. Збільшення зображень при кліку та можливість їх гортання в модальному вікні.
6. Обробка помилок (якщо зображень за запитом не знайдено — виводиться
   повідомлення про помилку).
